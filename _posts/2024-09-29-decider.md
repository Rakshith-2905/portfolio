*ECCV 2024 · [Paper](https://arxiv.org/abs/2408.00331) · [Code](https://github.com/Rakshith-2905/PRIME)*

**Rakshith Subramanyam\*, Kowshik Thopalli\*, Vivek Narayanaswamy, Jayaraman J. Thiagarajan** (\*equal contribution)

Classifiers fail quietly. They latch onto spurious cues (water behind a bird, hair color tied to gender), struggle on under-represented classes, and break under corruptions and domain shifts, all while staying confident. Scores built from the model's own output, like max softmax probability or entropy, inherit the same blind spots.

**DECIDER** (Debiasing Classifiers to Identify Errors Reliably) brings in an outside opinion. It uses foundation models to build a second, "debiased" version of the classifier that is forced to rely only on the attributes that *should* matter for each class, then flags a prediction as a likely failure when the two models disagree.

## How it works

1. **Ask an LLM what matters.** For every class, GPT-3 is prompted to list visually descriptive attributes ("List visually descriptive attributes of a *waterbird*"). These are the task's core attributes.
2. **Train a Prior-Induced Model (PIM).** PIM shares the classifier's architecture and takes its early-layer features, but its last layer projects into CLIP's embedding space. It scores each class by cosine similarity to the CLIP text embeddings of that class's attributes, so it can only win by using those attributes.
3. **Score disagreement.** The failure score is the cross-entropy between the original classifier's prediction and PIM's. High disagreement means the classifier is probably leaning on something it shouldn't.
4. **Explain the failure.** DECIDER learns a weight per attribute so PIM's output matches the original classifier. Attributes whose weight collapses are the ones the classifier is ignoring, which gives a human-readable reason for the error.

## Where it was tested

Spurious correlations (Waterbirds, CelebA), class imbalance (a skewed Cats vs Dogs split), synthetic corruptions (CIFAR-100-C) and domain shift (PACS, DomainNet, ImageNet to ImageNet-Sketch), against MSP, entropy, energy and ensemble-disagreement baselines. Quality is measured by Matthews correlation (MCC) between predicted and actual failures.

| Benchmark | Best baseline (MCC) | DECIDER (MCC) |
| --- | --- | --- |
| Waterbirds | 0.28 (entropy) | **0.46** |
| CelebA | 0.37 (entropy) | **0.49** |
| Cats vs Dogs (imbalanced) | 0.34 (energy) | **0.55** |
| CIFAR-100 | 0.51 (entropy) | **0.53** |
| CIFAR-100-C | 0.38 (entropy) | **0.40** |

The gains are largest exactly where confidence-based scores are weakest: spurious correlations and imbalance. Ablations show the pieces matter: replacing PIM with off-the-shelf CLIP drops MCC on Waterbirds from 0.46 to about zero, and feeding PIM irrelevant or too few attributes pulls it back toward the baseline.

## Why it matters

Detecting failures before they reach a user is the same problem whether the model is a classifier or an LLM. DECIDER's idea, check a model against an independent, knowledge-grounded view of the task and treat disagreement as a warning, is the thread that runs through my later work on reliability.
